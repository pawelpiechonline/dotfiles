# Global agent instructions

- Do not use the em dash. Use a hyphen "-" instead.
- Do not add your agent name as co-author in a commit message.
- Do not edit CHANGELOG.md or a file that is marked as auto-generated.
- Write markdown as near plain text. Use a header only when it helps the reader.
- Do not use bold or italics in markdown.
- Do not use backticks or ticks for a path, a command, a name, or another word.
- Use a fenced code block only for code.
- Prefer quality, simplicity, robustness, scalability, and maintainability to development cost.
- Keep a reply short and direct. Start with the answer or with what you did. Do not restate my question.
- Do not use filler, praise, emojis, or goodbyes.
- Ask me a question when the task is not clear or can have more than one meaning. Do not guess. Do not select an option on your own.
