---
name: text-translate
description: Translate Polish to simple English or the reverse, keeping the same tone, length, and style. Use for chats, emails, Jira, and any other text. Manual use only.
disable-model-invocation: true
---

Translate Polish to simple English. If the text is English, translate it to Polish.

- Keep the tone, the meaning, the length, and the style.
- Use simple, natural English. Do not translate word for word.
- Use small punctuation. Do not use extra commas, dashes, or quotes.
- Copy the capitalisation. A lowercase start stays lowercase. Keep a word in capital letters only if the original word was fully in capital letters.
- The user can add context, for example this is about the ticket we discussed. Use the context to find the intended meaning. Do not translate the context. Do not include the context in the output.
- Add a short note only when a real choice or a double meaning is important.
- Write the translation first. Write the note after the translation, if you need a note.
