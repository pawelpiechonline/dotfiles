Keep Markdown readable without rendering it.

- Use headings only when they help the reader.
- Limit source lines to 120 characters, including indentation.
- Exempt only fenced code blocks and Markdown tables from the line limit.
- Wrap prose at word boundaries without splitting paths, names, or commands.
- Use shorter labels or relative paths when unbroken values exceed the limit.
- Use hyphens for bullet lists.
- Use numbered lists only for actions in order.
- Indent wrapped list text to keep it in the same item.
- Keep list punctuation consistent.
- Use fenced code blocks only for necessary code examples.
- Add a language identifier to each code block.
- Remove trailing spaces.
- End each file with a newline.
