  English. Use this skill for a new skill or a change to an existing skill.

Create clear, focused skills that a small model can follow reliably.

- Find the skill named or described by the user.
- Read the full skill and its supporting files before editing.
- Preserve existing instructions and meaning unless the user requests changes.
- Edit SKILL.md in place when rewriting a skill.
- Read each required reference before you apply its rules.
- Follow ../how-to-use-markdown/SKILL.md for Markdown formatting.
- Follow reference/structure.md when you create or organize a skill.
- Follow reference/writing.md for all skill text.
- Follow reference/tables.md when the skill has supporting files.
- Follow reference/validation.md before you finish.
- Show the new or changed SKILL.md to the user.

| File                    | Task                      | Description                     |
| ----------------------- | ------------------------- | ------------------------------- |
| reference/structure.md  | Create or organize skills | Scope, metadata, and references |
| reference/writing.md    | Write or rewrite text     | Simple English and clear rules  |
| reference/tables.md     | List supporting files     | File paths and usage conditions |
| reference/validation.md | Check the finished skill  | Content, paths, and examples    |
