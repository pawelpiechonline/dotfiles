Write instructions in ASD-STE100 Simplified Technical English.

- Use at most 20 words in procedure sentences and 25 in descriptive sentences.
- Give one direct order per procedure sentence.
- Use active voice and simple present tense.
- Use the same word for the same meaning.
- Use must for requirements, can for possibilities, and do not for prohibitions.
- Use simple words, except when an exact technical term is necessary.
- Do not put more than three nouns together.
- Keep enough context for a small model to follow each rule.
- Remove words only when the meaning stays clear.
- Do not repeat rules, except when a reference needs essential context.
- Do not add summaries, praise, or filler.
- Use ordered steps only for actions that must happen in sequence.
- Give each such step a level 2 heading with its rules below.
- Keep examples small and consistent with the rules.
- Do not add an example that only repeats another example.
